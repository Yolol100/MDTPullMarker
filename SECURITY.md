# Security policy

Security fixes are applied to the current `main` source and newest release candidate.

Do not publish credentials, private keys, exploit details, or user data in a public issue. Prefer GitHub private vulnerability reporting from the repository Security tab when available. If private reporting is unavailable, contact the repository maintainer through the GitHub account before sharing sensitive reproduction details.

For gameplay-safety reports, include the WoW build, MDT version, group state, challenge/combat state, affected route/pull and whether the failure was fail-closed or produced an incorrect marker action.
